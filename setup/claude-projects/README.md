# Claude 全プロジェクトの退避・再構築

Claude アカウント移行（[projects/2026-11-claude-account-migration.md](../../projects/2026-11-claude-account-migration.md)）で、**旧アカウントの全プロジェクト**を新アカウントへ作り直すための置き場。
1プロジェクト = 1ファイル（`<slug>.md`）。秘密情報は書かない。

## 一覧

| プロジェクト名 | ファイル | 退避 | 新アカウントで再構築 |
|---|---|---|---|
| 私の人生設計 | [jinsei-sekkei.md](jinsei-sekkei.md) | 済 | 未 |
| （他のプロジェクト） | TBD | 未 | 未 |

## 退避手順（旧アカウントで、プロジェクトごとに）
1. そのプロジェクトの「プロジェクト指示」をコピーして控える（設定画面から）。
2. ライブラリ（ナレッジ/ファイル/GitHubリポジトリ）の一覧を控える。ファイル本体は手元に保存。
3. そのプロジェクトで下の「退避プロンプト」を送る → 出力された Markdown を「私の人生設計」スレッドに貼る → `setup/claude-projects/<slug>.md` として保存してもらう。

### 退避プロンプト（そのまま送る）

```text
このプロジェクトを別のClaudeアカウントで作り直すための引き継ぎ資料を、Markdownで1つ出力して。
秘密情報（パスワード、APIキー、個人番号等）は含めないこと。
見出しは次のとおり:
# <プロジェクト名>
## 目的
## プロジェクト指示（現在の文面をそのまま）
## ライブラリ（ファイル名・GitHubリポジトリ名の一覧と用途）
## メモリ（あなたが覚えている前提・決定事項・好み・進行中タスクをすべて箇条書き）
## 進行中の作業と次の一手
## 再構築後の最初のメッセージ（新しいClaudeに送ると、この前提をメモリに保存し直せる文面）
```

## 再構築手順（新アカウントで、プロジェクトごとに）
1. 新規プロジェクト作成 → 各ファイルの「プロジェクト指示」を貼る。
2. ライブラリに GitHub リポジトリ / ファイルを入れる（新アカウントで GitHub 連携済みであること）。
3. 各ファイルの「最初のメッセージ」を送る → 動作確認。
4. 上の一覧の「再構築」を済にする。

# 2026-11-14 パスキーは Bitwarden に保存してよい

- ステータス: 採用

## 背景
- パスキーをハードウェアキー（YubiKey）だけに置くと、端末ごと・サービスごとの登録や認証が煩雑。
- パスワードとパスキーを同じ Vault に置くと「多要素」ではなく実質1要素（Vault 突破＝全突破）になるトレードオフがある。

## 決定
- 個人用途では、パスキーを Bitwarden に保存することを許可する（デフォルト）。
- 例外: Tier 0（Bitwarden / Proton / Cloudflare / メインGoogle）は YubiKey を必ず登録する（Bitwarden 自身のパスキーは Bitwarden に置けないため。他3つは Vault 喪失時の復旧経路を確保するため）。

## 理由
- 利便性を優先しても、Vault 自体を YubiKey で保護しているため個人用途のリスクは許容範囲（本人判断）。
- 端末間同期されるため、端末紛失時もパスキーを失わない。

## 影響・リスク
- Bitwarden の Vault が侵害されると、パスキー保存先のサービスは全て突破される → Bitwarden のマスターパスワード強度と YubiKey 2FA が生命線。
- 業務用アカウントにはこの決定を適用しない（会社のポリシーに従う）。
